# Security policy

Please report vulnerabilities **privately**, not in a public issue: use GitHub's
[private vulnerability reporting](https://github.com/brianv0/rico/security/advisories/new)
for this repository. Include what you found, how to reproduce it, and what it affects.

Rico handles GitHub OAuth tokens for the hosted service at `ricorico.dev`, so reports about sign-in, sessions, the
GitHub proxy (`src/github.js`), the sanitising of rendered markdown, or the response headers are especially welcome.
You will get an answer as soon as I can give one; this is a one-person project.
