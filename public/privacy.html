Privacy

Last updated 28 November 2026

Rico (ricorico.dev) is a free tool for reviewing the markdown in GitHub pull requests. It is run by Brian Van Klaveren as an open-source project (source). This page says what the hosted service collects and why. Running Rico yourself with npm start collects nothing: it never contacts anyone but GitHub.

What Rico does not store

Pull request contents, file contents and comment text pass through Rico's server to and from GitHub and are not kept. The one exception is a one-minute copy of public pull request data, cached at Cloudflare's edge so many visitors can share one request to GitHub. Comments you post live on GitHub, under GitHub's terms and privacy statement, not here. Rico sells nothing, shows no ads and shares nothing with anyone except the service providers named here.

Cookies and local storage

  • rico_session: your encrypted sign-in, described above. Set only when you sign in.
  • rico_oauth: a random value that protects the sign-in handshake. Lasts ten minutes.
  • Your browser's local storage keeps your theme choice, files you marked Viewed, the comment display mode and any unsent comment text. It never leaves your browser.

These are strictly necessary for the features you use, so Rico shows no cookie banner. There are no advertising or tracking cookies.

The GitHub permission

By default Rico asks GitHub for the public_repo permission. To review private repositories you must choose to allow GitHub's broader repo permission. Rico uses it only to read the pull request you open and post the comments you write. You can remove Rico's access at any time under GitHub › Settings › Applications.

Where it runs

Rico runs on Cloudflare's global network, so your requests may be handled in other countries than your own. Cloudflare is the only service provider that processes data for Rico, under its own data processing terms, which include standard contractual clauses for transfers.

Your choices and rights

Whether you are in the EU/UK (GDPR) or California (CCPA/CPRA) or elsewhere, you can ask what Rico holds about you, ask for it to be corrected or deleted, or object to its use. In practice: sign out to delete your session and revoke your token; usage records disappear on their own after about three months; and you can ask for them to be removed sooner by opening an issue (do not include anything private) or, for something sensitive, using the contact in SECURITY.md. Rico does not sell or share personal information for advertising and does no automated decision-making. You may also complain to your data protection authority.

The legal basis for the above is legitimate interest in running, securing and improving the service, and, for sign-in, performing the service you asked for. Rico is not directed at children under 13, and GitHub's own minimum age applies.
